## SEO Strategy Notes

### Keyword Optimization Guidelines
- **Primary Keywords**: Integrated naturally in title and first 100 words
- **Secondary Keywords**: Used in subheadings, alt text, and throughout content
- **Long-tail Variations**: Incorporated in FAQ sections and internal linking
- **Local Intent**: When applicable, include location-based modifiers

### Title Tag Best Practices
- **Length**: 50-60 characters optimal, max 70 characters
- **Primary Keyword**: Include near the beginning when possible
- **Brand**: Include "| Apsics Media" when space allows
- **Emotional Triggers**: Use power words like "Complete", "Proven", "Free"
- **Numbers**: Include specific numbers and timeframes when relevant

### Meta Description Strategy
- **Length**: 140-160 characters optimal
- **CTA Include**: Action words like "Get", "Download", "Calculate"
- **Value Proposition**: Clear benefit statement
- **Social Proof**: Include user counts, testimonials when space allows
- **Urgency/Scarcity**: When appropriate for the content type

### URL Structure
- **Slug Format**: `/content-type/primary-keyword-topic-guide`
- **Hyphens**: Use hyphens to separate words, not underscores
- **Length**: Keep under 75 characters when possible
- **Descriptive**: URL should indicate content type and topic clearly

### Internal Linking Strategy
- **Template Cross-Links**: Blog posts link to relevant calculators and playbooks
- **Topic Clustering**: Group related content around main topic themes
- **Authority Flow**: Link from high-authority pages to new content
- **Anchor Text**: Use descriptive, keyword-rich anchor text

### Featured Snippet Optimization
- **FAQ Sections**: Structure questions to target voice search and featured snippets
- **List Format**: Use numbered lists and bullet points where appropriate
- **Definition Boxes**: Include clear definitions for key terms
- **How-To Structure**: Use step-by-step formats for instructional content

### Schema Markup Implementation
- **Article Schema**: All blog posts include comprehensive article markup
- **WebApplication Schema**: All calculators include tool-specific markup
- **Course Schema**: All playbooks include educational content markup
- **FAQ Schema**: Include FAQ structured data for featured snippets
- **Organization Schema**: Consistent business information across all pages

This SEO metadata is optimized for Apsics Media's startup-focused ICP while targeting low-competition, high-intent keywords that align with the template system and business objectives.
