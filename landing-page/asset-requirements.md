# Asset Requirements for APSICS Media Landing Pages

## Overview

This document outlines all visual assets, multimedia content, and graphic elements required to complete the APSICS Media landing pages and maintain consistent brand standards across all touchpoints.

---

## 🎯 Alytics Page Asset Requirements

### Hero Section Assets
- [ ] **Background Video/Animation** (Optional)
  - Duration: 10-15 seconds, seamless loop
  - Format: MP4, WebM
  - Resolution: 1920x1080 minimum
  - Theme: Abstract data visualization or trending content visualization
  
- [ ] **Floating Logo Elements** 
  - 8-10 recognizable platform/tool logos (TikTok, Instagram, Facebook, LinkedIn, etc.)
  - Format: SVG preferred, PNG backup
  - Size: 40x40px to 80x80px
  - Style: Monochrome or subtle color

### Weekly Delivery Showcase Section
- [ ] **Template Preview Screenshots**
  - 4 platform-specific template mockups:
    - TikTok content template example
    - Facebook ad template example  
    - Instagram story template example
    - LinkedIn post template example
  - Format: PNG with transparency
  - Dimensions: 16:9 aspect ratio, 400x225px minimum
  - Style: Clean, professional, with placeholder content

- [ ] **Custom Script Delivery Screenshots**
  - Sample script performance dashboard
  - Hook performance scoring interface (showing 23/25 score)
  - Trending analysis results page
  - Format: PNG, high-resolution
  - Include realistic but anonymized data

### Service Tiers Section
- [ ] **Pricing Tier Icons**
  - Crown icon for Founder's Special (premium gold/yellow)
  - Lightning bolt for Starter tier (blue)
  - Trending arrow for Growth tier (green)  
  - Building/enterprise icon for Scale tier (purple)
  - Format: SVG preferred
  - Style: Consistent with Framer design system

### Testimonials Section
- [ ] **Client Testimonial Photos**
  - 3 professional headshots of diverse startup founders
  - Format: PNG with transparent background or square crop
  - Dimensions: 200x200px minimum
  - Style: Professional, approachable, diverse representation
  - **Note**: Must be authentic client photos, not stock imagery

- [ ] **Company Logo Placeholders**
  - 6 startup company logos for social proof
  - Format: SVG preferred, PNG backup
  - Style: Clean, professional, recognizable
  - Include mix of B2B SaaS, e-commerce, and mobile app companies

### Weekly Process Visualization
- [ ] **Step-by-Step Process Graphics**
  - Monday delivery illustration
  - Copy & customize workflow graphic
  - Launch & scale results visualization
  - Format: SVG illustrations
  - Style: Consistent with Framer MCP aesthetic

## 📋 Asset Delivery Specifications

### File Naming Convention
```
category-element-variant-size.extension
Examples:
- testimonial-photo-sarah-400x400.png
- logo-company-acme-horizontal.svg  
- template-preview-tiktok-400x225.png
- icon-feature-target-24x24.svg
```

### Folder Structure
```
assets/
├── logos/
├── testimonials/
├── templates/
├── icons/
├── screenshots/
├── graphics/
└── photography/
```

### Quality Requirements
- **Images**: Minimum 300 DPI for print, optimized for web
- **Screenshots**: Actual interface captures, not mockups
- **Logos**: Vector format (SVG) with PNG fallbacks
- **Photos**: Professional quality, properly licensed
- **Icons**: Consistent style, appropriate contrast ratios

## ✅ Asset Approval Process

1. **Review**: All assets reviewed against brand guidelines
2. **Optimization**: Web performance optimization applied
3. **Testing**: Cross-browser and device testing
4. **Implementation**: Systematic replacement of placeholders
5. **QA**: Final quality assurance and consistency check
