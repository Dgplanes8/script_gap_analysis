# Framework Images Creation Guide
*Complete instructions for creating cohesive, professional images for the 4-box grid*

## Design Principles for Cohesion
- **Consistent visual style**: Clean, minimal, professional SaaS aesthetic
- **Unified color palette**: Blue (#126DFB), Orange (#F97316), Green (#10B981), Purple (#8B5CF6)
- **Similar complexity level**: Each image should have 3-5 main visual elements
- **Complementary layouts**: Different but harmonious compositions
- **Professional spacing**: Generous white space, clean margins

## 1. Customer Research Dashboard (Step 1)
*Theme: Data collection and customer insights*

### Option A: Market Research Dashboard
**Visual Concept**: Customer analytics interface with demographic data
**Layout Elements**:
- Left side: Vertical bar chart (5-6 bars, varying heights)
- Top right: 2 circular progress indicators (73%, 89%)
- Bottom right: Simple donut chart with 3-4 segments
- Background: Clean white with subtle grid lines
- Colors: Primary blue bars, orange accent highlights

**DIY Instructions (Figma/Canva)**:
1. Create 1600x1000px canvas, white background
2. Add subtle gray grid overlay (opacity 10%)
3. Left third: Create 6 vertical rectangles (different heights), blue color
4. Top right: Two circles with partial fill (progress indicators)
5. Bottom right: Donut chart using colored segments
6. Use shadows: 0px 4px 12px rgba(0,0,0,0.1)

## Color Palette Reference
- **Primary Blue**: #126DFB (main brand color)
- **Orange**: #F97316 (accent, energy)
- **Green**: #10B981 (success, growth)
- **Purple**: #8B5CF6 (creativity, premium)
- **Gray**: #6B7280 (neutral elements)
- **Light Gray**: #F8F8F8 (backgrounds)
- **White**: #FFFFFF (cards, clean areas)

## Technical Specifications
- **Dimensions**: 1600x1000 pixels (16:10 aspect ratio)
- **File Format**: WebP (for web optimization)
- **File Size**: Target 100-200KB each
- **Quality**: High resolution for crisp display
- **Shadow Style**: 0px 4px 12px rgba(0,0,0,0.1)
- **Border Radius**: 8-12px for cards and elements

## Final Checklist
✅ All 4 images use complementary but distinct layouts  
✅ Consistent color palette across all images  
✅ Professional, clean aesthetic  
✅ No repetitive visual elements between images  
✅ 16:10 aspect ratio maintained  
✅ Optimized for web display  
✅ Work well with gradient overlays  
✅ Support text placement over them
