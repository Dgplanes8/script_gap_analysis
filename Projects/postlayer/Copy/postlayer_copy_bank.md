# PostLayer Performance-Scored Copy Bank
*High-converting hooks and headlines for 3 validated ICP segments*

## Copy Development Framework Applied

Based on validated concepts from ICP research and using proven direct-response copywriting principles, each hook has been scored using the 5-dimension framework:
1. **Attention Capture** (1-5): Will it stop the scroll?
2. **Emotional Resonance** (1-5): Does it trigger specific emotions?  
3. **Benefit Clarity** (1-5): Is the core promise immediately clear?
4. **Call-to-Action Strength** (1-5): Does it create urgency?
5. **Memorability** (1-5): Contains "sticky" elements?

**Decision Guide:**
- 21-25: Green light - exceptional potential
- 16-20: Proceed with optimizations  
- Below 16: Rework - unlikely to perform
